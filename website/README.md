# Rulence

One machine. Consistency across all agents.

Value in Consistency.

Rulence is a free, local-first reasoning governance layer for AI agents. The
website presents the launch surface for the CLI, MCP server, Docker image,
runner installers, and public documentation links.

Website: https://rulence.com

## Website

The website is built with Zola and managed with Bun scripts.

```bash
bun run dev
bun run check
bun run build
bun run build:desktop
```

`bun run build:desktop` exports the generated site to:

```text
/Users/aumordecade/Desktop/Rulence Website
```
